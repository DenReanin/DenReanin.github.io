01 / PLATFORM & SERVICESWhat runs in the lab

The host is a Debian-based network storage system running Docker Compose and KVM/QEMU. SSD storage is reserved for container layers, databases and virtual machine disks; the larger Btrfs pool holds photos, documents and media.

Network corePi-hole provides local DNS, DHCP and filtering. WireGuard provides encrypted remote access; DDNS keeps the VPN endpoint reachable as the public IP changes.

Personal servicesImmich manages photo backup and search. Jellyfin streams a read-only media library with Intel Quick Sync / VAAPI hardware-assisted transcoding. Homepage provides a private service dashboard.

Compute & certificatesA Debian virtual machine runs on KVM/QEMU. acme.sh automates Let's Encrypt certificate renewal through DNS-01 validation.

02 / NETWORK & SECURITYLimit exposure, isolate services
  • Administrative web interfaces are restricted to the local network or VPN; WireGuard is the sole intended remote entry point.
  • Pi-hole uses a macvlan network for LAN DNS and DHCP. A persistent host-side shim resolves the Linux host-to-macvlan isolation constraint.
  • Split-horizon DNS returns private answers on the home network while public DNS supports remote VPN access. DNS-01 certificate validation avoids exposing an HTTP validation service.
  • UPnP and DMZ are disabled. Containers run without root where possible, application containers do not receive the Docker socket, and media libraries are mounted read-only.
  • ClamAV checks incoming files before they are moved into shared libraries. Secrets are created on the host, permission-restricted and excluded from Git.
03 / DATA & RECOVERYA three-layer 3-2-1 strategy

01SnapshotsDaily Btrfs copy-on-write snapshots provide quick recovery from accidental changes.

02Local replicaCritical personal, study and security data is mirrored to a physically separate disk.

03Offline copyAn external drive is connected only for manual backup, then disconnected.

Recovery notes: Immich restores require both the photo library and its database backup. Virtual-machine disks are copied only after the VM is stopped to protect filesystem consistency.

04 / MONITORING & AUTOMATIONMake operations observable and repeatable

Homepage tracks host health without exposing the Docker socket. Pi-hole query statistics, WireGuard peer telemetry, antivirus results and SSH authentication logs provide focused visibility into the services and access paths.

Scripts and cron handle maintenance, certificate renewal, network initialization and queued jobs. A scheduled security-reporting workflow uses a maker-checker review pattern and a restricted tool allowlist.

  • Systemd restores the host-side network shim after reboot.
  • Download and validation jobs record clear success, partial and error states instead of trusting a process exit code alone.
  • Operational runbooks capture safe DHCP handover, backup consistency and recovery steps.
05 / ENGINEERING LESSONSFailures that improved the design
  • macvlan isolation: the Linux host cannot communicate directly with child interfaces, so a persistent shim provides a deliberate host-side path.
  • Container devices: exposing a device node is not the same as granting device access; container runtime permissions must also allow it.
  • SSH configuration: OpenSSH include order and first-match behavior matter, so hardening directives must be placed where they take effect.
  • DHCP handover: establish stable host networking before changing which service assigns addresses.
  • Recovery consistency: restore Immich's database and photo library together, and copy virtual-machine disks only while the VM is stopped.
  • Storage semantics: Btrfs subvolume boundaries affect large moves; consistent lowercase naming avoids case-collision problems across Linux and SMB clients.
